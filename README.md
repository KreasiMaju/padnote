# PadNote Bug Reports

Report bugs in [PadNote](https://padnote.kreasimaju.id) here. This repository only holds bug reports. PadNote's source code is not hosted here.

## Reporting a bug

1. Search the [existing issues](../../issues) first. If your bug is already there, add your details to it.
2. Otherwise, [open a new bug report](../../issues/new/choose) and fill in the form.

Please include:

- Your PadNote version (bottom of the Help menu)
- Your macOS version and Mac model
- Steps to reproduce the problem
- A screenshot or screen recording, if you have one

Issues are public. Do not post private file contents, passwords or keys.

Before reporting, update to the latest version with Help > Check for Updates or `pn --update`. The bug may already be fixed.
